## Vulkan Tutorial (With Jai Language)

> This repository will host a Chinese translation of [Vulkan Tutorial](https://vulkan-tutorial.com/) by **Alexander Overvoorde**. The original tutorial was structured using daux.io, but it has been converted to `mdbook` format for easier maintenance and deployment.

I copied the [mdbook format] documentation from [SangGuKin/VulkanTutorial](https://github.com/SangGuKim/VulkanTutorial/)

## Deployment

Online Preview: [https://qiekn.github.io/poison/]

Local Server:

```bash
# install mdbook
cargo install mdbook

# Serve the book locally
mdbook serve --open
```
